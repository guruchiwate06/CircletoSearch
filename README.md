# ScreenLens

A Windows desktop application built with Python 3.11+ and PySide6.

## Setup

1. **Create and activate a virtual environment:**

   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

2. **Install dependencies:**

   ```bash
   pip install -r requirements.txt
   ```

## Run the Application

```bash
python main.py
```
